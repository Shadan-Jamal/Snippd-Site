# Snippd site

Marketing site for [Snippd](https://github.com) (CSR, Vite + React + Tailwind + Aceternity + wouter).

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Routes

- `/` — landing
- `/docs` — docs

Static hosts that serve deep links need an SPA fallback to `index.html`.
